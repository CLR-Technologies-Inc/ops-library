# DMAIC tollgate checklist

At each tollgate, the Champion reviews the evidence before the team moves to the next phase.

## Define
- [ ] Charter signed by the Champion and process owner
- [ ] Problem and goal stated in measurable terms
- [ ] Scope bounded (first and last process steps named)
- [ ] SIPOC complete
- [ ] Voice of the customer gathered and translated into CTQs with specifications
- [ ] Estimated financial benefit reviewed by finance

## Measure
- [ ] Process map of the current state (as it is actually done, not as written)
- [ ] Data collection plan (what, where, how, how many, who)
- [ ] Measurement system analysis passed: Gauge R&R %Study var under 30% (ideally under 10%) and ndc of 5 or more
- [ ] Baseline stability checked with a control chart
- [ ] Baseline capability (Cp/Cpk, Pp/Ppk) or DPMO and sigma level calculated
- [ ] Normality checked, or a suitable non-normal method used

## Analyze
- [ ] Potential causes listed (fishbone, 5 Whys, FMEA)
- [ ] Causes narrowed with data (Pareto, stratification)
- [ ] Root causes verified statistically (hypothesis tests, regression, DOE screening)
- [ ] Size of each cause's effect quantified

## Improve
- [ ] Solutions generated and selected against criteria
- [ ] Settings optimized with designed experiments where relevant
- [ ] Mistake-proofing (poka-yoke) used ahead of inspection or retraining
- [ ] Pilot run, with the improvement confirmed statistically
- [ ] New capability calculated
- [ ] FMEA updated for the new process
- [ ] Implementation plan and risks agreed

## Control
- [ ] Control plan in place (what is monitored, how often, chart type, reaction plan)
- [ ] SPC charts running on the key outputs and inputs
- [ ] Standard work and procedures updated, and people trained
- [ ] Gain sustained over the agreed period
- [ ] Financial results validated by finance
- [ ] Process ownership handed over and the project closed
- [ ] Lessons learned shared, and fixes copied to similar processes
