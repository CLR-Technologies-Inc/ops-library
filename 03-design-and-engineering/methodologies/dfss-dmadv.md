# Design for Six Sigma (DFSS) and DMADV

DFSS applies Six Sigma when designing a **new** product or process, or when an existing process can't be fixed with [DMAIC](../../01-continuous-improvement/methodologies/dmaic.md) and has to be redesigned. Its most common cycle is **DMADV**.

| Phase | Purpose | Typical tools in this library |
| --- | --- | --- |
| **Define** | Set design goals that match customer needs and company strategy. | Project charter, VOC, SIPOC |
| **Measure** | Identify the CTQs (Critical-To-Quality characteristics). Measure product capability, production process capability, and risks. | CTQ tree, [QFD](../tools/), [Gauge R&R](../../02-quality-and-statistics/tools/), [capability study](../../02-quality-and-statistics/tools/) |
| **Analyze** | Develop and evaluate alternative designs. | [FMEA worksheet](../tools/excel/fmea-worksheet.xlsx), Pugh matrix, [DOE](../../02-quality-and-statistics/tools/) |
| **Design** | Build the improved design from the analysis. | [DOE](../../02-quality-and-statistics/tools/), tolerance analysis, Taguchi methods |
| **Verify** | Verify the design, run pilots, start up the production process, and hand it to the process owners. | [Capability study](../../02-quality-and-statistics/tools/), [control charts](../../02-quality-and-statistics/tools/), control plan |

Practitioners use other DFSS cycles too, such as IDOV (Identify, Design, Optimize, Validate) and DMADOV (which adds Optimize).
